## 시도 #3 — 옵션 B (취소됨)

옵션 B (init_noise_std 0.5만 변경)로 D4.5 재학습 계획했으나, 발표 시나리오 재정의 후 취소.

**취소 사유:**
±50N robustness 학습 (시도 #1~#3 모두 D4.5 ±7N 출발)이 우리 발표 시나리오와 mismatch 발견.
사용자 발표 시나리오는 **야외 보도블록 평지 보행 + 제자리 서서 SO-ARM으로 물건 집기**.
이 경우 base에 가해지는 외력은 ±5N 이내, ±50N은 격투/공격 시나리오에 해당 (불필요).

→ **19-stage curriculum (D4.5 → E8) 폐기**, 새 단일 학습으로 전환.

## 발표 시나리오 정의 (2026-05-01 결정)

**환경:** 학교 축제 야외 시연
- 보도블록 바닥 (단차 5~10mm, 마찰 0.3~1.0)
- 약간의 경사 (1~2°, 배수용)

**시나리오:**
1. 평지 보행 (vx ≤ 0.5 m/s, 팔 고정)
2. 제자리 서기 + SO-ARM 으로 물건 집기 (정지 + mass 변동)

**base 외력 추정:** ±5N 이내 (블록 단차 충격 펄스 + 경사 정적 + 팔 reaction)

**±50N 학습 폐기 사유:**
- 학습 effort_limit 6 Nm 으로 ±50N 회복에 필요한 ankle 토크(~15 Nm) 부족 → 실기 시연 불가
- BHL 학습 표준 (±2N) 의 25배 → 검증 안 된 학습 영역
- 시도 #1, #2 모두 ±7N 부터 학습 실패
- 우리 demo 시나리오와 무관 (격투용 robustness 아님)

## BHL 본가 학습 방식 (2026-05-01 조사 결과)

| 항목 | BHL 공식 | 의미 |
|------|---------|------|
| max_iterations | **6000** (단일) | curriculum 없음 |
| 외란 force | ±2 N (reset 모드, episode 1회만) | 사실상 안 씀 |
| mass 변동 | -1.0 ~ +2.0 kg (startup) | domain randomization으로 robustness |
| friction 변동 | 0.4 ~ 1.2 (startup) | |
| actuator gain | 0.8 ~ 1.2 (startup) | |
| terrain | flat plane only | rough 안 씀 |
| velocity 범위 | ±0.5 m/s (lin_vel_x) | |

**핵심:** BHL은 외란 거의 안 쓰고 **도메인 랜덤화 (mass, friction, gain)** 로 robustness 만듦.
