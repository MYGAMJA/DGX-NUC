#### Phase iv — +x 방향 한계 sweep

| Shift | 보행 vx=0.3 | 정지+2kg |
|-------|:-----------:|:--------:|
| +10mm (1.5%) | 250/250 | 250/250 |
| +20mm (3.1%) | 250/250 | 250/250 |
| +30mm (4.7%) | 250/250 | 250/250 |
| **+40mm (6.3%)** | 36/250 ⚠ | **250/250** ✅ |
| +50mm (7.8%) | 33/250 ⚠ | 250/250 ✅ |
| **+70mm (11%)** | 27/250 ❌ | **250/250** ✅ |
| +100mm (15.7%) | 23/250 ❌ | 45/250 ⚠ |

#### 핵심 발견

1. **정지 자세 + 앞쪽(+x) shift는 +70mm (11%) 까지 완벽** — 사용자 시나리오의 안전 영역 한참 안쪽
2. **뒤쪽(-x) shift는 모든 시나리오 즉시 fall** — footprint center가 base 약간 앞에 있어 -x는 footprint 밖
3. **보행 + +x shift는 30mm가 cliff** (40mm부터 fail)
4. **z 방향 shift (위/아래)는 정책이 매우 약함**

#### 사용자 시나리오 (정지 + SO-ARM 물건 집기) — 안전 매트릭스

| 물건 무게 × 거리 | CoM shift | 결과 |

| 1.0kg × 0.4m | +1.9 cm | ✅ 250/250 |
| 1.5kg × 0.4m | +2.8 cm | ✅ 250/250 |
| 2.0kg × 0.5m | +4.6 cm | ✅ 250/250 |
| 3.0kg × 0.5m | +7.0 cm | ✅ 250/250 (한계 직전) |

→ 발표 시연 (1~1.5kg) 은 안전 영역의 한참 안쪽.

## 5. 도메인 랜덤화 점검

### ✅ 학습에 포함됨 (BHL 표준)
- friction 0.4~1.2, base mass -1~+2kg (D4는 +1 고정), joint default ±0.05 rad
- actuator stiffness/damping × 0.8~1.2
- base external force ±5N interval, ±1.5N torque
- IMU ang_vel ±0.3 rad/s noise
- projected_gravity ±0.05 noise
- joint_pos ±0.05 rad noise
- joint_vel ±2.0 rad/s noise

### ❌ 학습 안 됨 (sim2real 위험)
- 모터 응답 지연 (latency) — 가장 큰 위험
- 링크별 CoM/mass (base 외)
- 링크 inertia tensor
- armature randomization
- action/observation delay
- joint friction (Coulomb)
- 모터 saturation curve

→ BHL 본가도 동일 수준이지만, sim2real에 추가 randomization은 도움됨.
