## 2. 결선 방법 (우리 버전)

### 2.1 큰 원칙 — 전원과 CAN은 다르게 연결

| | 전원 (24V) | CAN 신호 (H/L/G) |
|---|---|---|
| 연결 방식 | **커넥터** (XT60/XT90) | **납땜** |
| 배선 구조 | **별 모양** — PDB에서 각 BESC로 따로 | **데이지체인** — BESC→BESC 줄줄이 |
| 이유 | 나중에 BESC 하나만 분리 가능하게 | 신호선이고 버스라 줄줄이 이어야 함 |

> 영상 팀은 전원도 커넥터로 줄줄이(데이지체인) 했지만, 우리는 PDB 쓰니까 전원은 각 BESC가 PDB에서 자기 선 하나씩 받는 별 모양 구조.

### 2.2 limb 개념
- limb = 팔이나 다리 한 짝.
- 우리 BHL은 다리만 사용 (팔은 SO-ARM 대체) → limb는 2개:
  - **왼다리** = BESC id 1, 3, 5, 7, 11, 13 (6개) = can0
  - **오른다리** = BESC id 2, 4, 6, 8, 12, 14 (6개) = can1
- "한 limb 결선" = 다리 하나의 BESC 6개를 데이지체인으로 다 잇기 = CAN bus 1개 완성.

### 2.3 CAN 선 납땜 ("선끼리 납땜"이 여기서 나옴)

색 약속: 노랑=H, 녹색=L, 검정=G

중간 BESC는 패드 1개에 선 2가닥 (앞에서 들어오는 선 + 다음으로 나가는 선):
1. 두 선 끝 피복 3mm 벗기기
2. 두 선 끝을 손가락으로 배배 꼬아 하나로
3. 꼰 것을 BESC 패드에 한 번에 납땜 (한 가닥씩 겹쳐 붙이기보다 튼튼)
4. 끝점 BESC(id=13, id=14)는 들어오는 선 1가닥만

**핵심 팁 — 한 번에 한 색씩** (영상 13:02~16:12):
- 그 limb의 모든 BESC에 노랑(H)만 쭉 → 녹색(L)만 쭉 → 검정(G)만 쭉
- 색 섞어가며 하면 헷갈림. 한 색 끝내고 다음 색.

납땜한 자리마다 열수축 튜브.

데이지체인 순서: 중간 BESC들의 물리적 순서는 자유 (CAN은 버스). 중요한 건 id=13/14가 줄의 끝, CANable이 반대쪽 끝.
```
can0(왼다리):  CANable#1 ─ [1,3,5,7,11 순서자유] ─ id=13 (끝, termON)
can1(오른다리): CANable#2 ─ [2,4,6,8,12 순서자유] ─ id=14 (끝, termON)
```

### 2.4 전원 선 — BESC에 붙이기
1. BESC + 패드(빨강), − 패드(검정)에 16~18 AWG 선 ~10cm 납땜
2. 납땜 자리 열수축 튜브
3. 선 끝에 XT60 달기
4. PDB 출력 ↔ BESC를 XT60으로 체결
5. PDB 입력 ↔ supply는 XT90 + 굵은 선(10~12 AWG)
6. 권장: XT90 메인에 60A급 퓨즈
7. 극성 엄수 — 빨강=+, 검정=−. DC 역결선 시 BESC 손상.

### 2.5 선 길이 & 라우팅 (영상에서 제일 강조)
- 길이: 너무 길면 걸림, 너무 짧으면 관절 못 움직임
- **조인트 돌아가는 부위엔 반드시 여유(슬랙) 남기기**
- limb 한쪽 끝 → 반대쪽 끝으로 한 방향 경로 정해서 쭉 (위→아래 왔다갔다 하면 비효율)
- 선들 모아 zip tie, 또는 메시 슬리빙(그물망 튜브)으로 감싸면 깔끔 (BHL 공식 빌더들이 쓰는 방법)
- 엔코더선 등 짧은 선은 BESC 바로 옆에 zip tie 고정

### 2.6 전원 인가 전 검증 (멀티미터)
- 단락 체크: 각 BESC + 와 − 사이 0Ω(단락) 아니어야. PDB 입력도 확인.
- 극성: PDB 출력 12쌍 모두 +가 빨강인지.
- 종단저항 체크: 각 버스 H-L 사이 저항 ≈ **60Ω** (CANable 120Ω ∥ 끝점 BESC 120Ω). 120Ω 나오면 한쪽만 종단된 것.
- **2-bus라 CANable 2개 — 두 번째 CANable의 120R 점퍼도 ON인지 반드시 확인** (기존 기록엔 1개만 확인됨).
- GND 연속성: 데이지체인 양 끝 사이 G-G 도통 (과거 함정 2번 — 검정선 빠짐).
- 결선 후 각 조인트를 full ROM으로 손으로 돌려보며 선이 당겨지거나 끼는지 확인.

### 2.7 주의사항
- **모터를 손으로 움직일 땐 천천히** — BLDC라 빨리 돌리면 역기전력(전류 역류)이 BESC로 들어감. Step 4 조인트 캘리브 때 12개 관절 손으로 미는데 부드럽게.
- **펌웨어 조인트 limit이 선을 지켜줌** — 관절이 한계 넘어 돌면 선 끊김. limit 범위 안에서 선 길이 잡기.
- 프레임 나사에 Loctite 243 (보행 진동 풀림 방지).
