# 0524 모터 인덱스 — BESC-USB(SWD) 전수 검증

각 BESC의 micro USB → ST-LINK V2 SWD 인터페이스로 flash page 직접 read한 결과.
**24V 전원·CAN 통신 불필요** (MCU만 ST-LINK 전원으로 동작). read-only 동작이라 보드에 영향 없음.

## 방법론

1. BESC의 micro USB → ST-LINK V2.1 (`/dev/ttyACM0`)
2. `st-flash read /tmp/idN_config_page.bin 0x0801F800 2048`
3. struct offset (motor_controller.h 기준):
   - `0x000`: device_id (u32)
   - `0x004`: firmware_version (u32)
   - `0x104`: Motor struct — pole_pairs (u32), torque_constant (f32), phase_order (i32), max_calibration_current (f32)
   - `0x114`: Encoder struct — cpr (i32, +12), position_offset (f32, +16), velocity_filter_alpha (f32, +20), **flux_offset (f32, +40 → 0x13C)**
4. Python little-endian IEEE754 해석

## 모터 프로파일 판별
- **M6C12** (= 6512 액추에이터에 들어가는 MAD 모터; hip × 3 + knee): `torque_constant ≈ 0.08958` (펌웨어 csx 수정값; 공식 BHL 표는 0.0919), `max_cal_I = 5A`
- **5010 110KV** (= 5010 액추에이터; ankle pitch + ankle roll): `torque_constant ≈ 0.11760` (공식 BHL `43_indepth_motor_char.md` 표 + 펌웨어 `motor_profiles.h` `MOTORPROFILE_MAD_5010_110KV` 와 일치), `max_cal_I = 3A`

> 5-24 이전 노트 (`docs/motor_calibration_2026-05-15.md`, `docs/WORKFLOW.md`)에서 같은 모터를 "ankle 변종"으로 표기. 5-24 `robot_configuration.backup.json` 교차검증으로 **5010 110KV 확정** → 이 표 안에선 "5010 110KV"로 통일.

## 비고

- BHL 매핑상 **id=9, 10은 사용 안 함**. 만약 보드에 device_id=9 또는 10이 들어있다면 별도 분류 필요 (이전 작업자의 잔재 또는 미사용).
- 이 파일은 **2026-05-24 전수 SWD 검증 전용** 추적표. `docs/motor_calibration_2026-05-15.md`의 종합 표와 별개로 유지.
- 진행 순서: 왼다리 → 오른다리.
